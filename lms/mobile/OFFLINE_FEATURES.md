# Offline Features Guide

This document explains how to use the offline features in the Frappe Learning Android app.

## Downloading Courses for Offline Use

1. **Browse Courses**: Navigate to the Courses section in the app
2. **Course Details**: Open a course you're enrolled in
3. **Download Button**: Tap the "Download for offline use" button
4. **Download Progress**: A progress bar will show the download status
5. **Completion**: Once downloaded, the course will be available offline

## Managing Offline Content

### Viewing Downloaded Courses

1. Open the app menu
2. Select "Offline Courses"
3. Browse your downloaded courses

### Removing Downloaded Content

1. Navigate to "Offline Courses"
2. Find the course you want to remove
3. Tap the trash icon
4. Confirm deletion

### Storage Management

1. Go to "Settings"
2. Under "Offline Content", view your storage usage
3. Use "Clear All" to remove all offline content

## Using Courses Offline

When you're offline:

1. The app will automatically detect your offline status
2. A network status indicator will appear
3. You can access all downloaded courses from the "Offline Courses" section
4. Your progress will be saved locally and synced when you reconnect

## Video Playback Settings

You can adjust video quality settings for downloads:

1. Go to "Settings"
2. Under "Offline Content", select your preferred video quality:
   - Low (480p) - Uses less storage
   - Medium (720p) - Balanced quality and size
   - High (1080p) - Best quality, uses more storage

## Data Usage Options

To control data usage:

1. Go to "Settings"
2. Toggle "Download over Wi-Fi only" to prevent mobile data usage

## Sync Behavior

When you go back online:

1. Your progress will automatically sync to the server
2. Any pending actions will be processed
3. You'll receive any missed notifications

## Security

- All downloaded content is securely stored and encrypted
- Content cannot be accessed directly through the device's file system
- Logging out of the app will not automatically delete offline content
- For security reasons, some features may require online verification even if content is downloaded

## Troubleshooting

If you encounter issues with offline content:

1. Check your device storage space
2. Try clearing the app cache (Settings > Apps > Frappe Learning > Storage > Clear Cache)
3. Ensure the app has storage permissions
4. Try downloading the content again

For persistent issues, you can use the "Clear All" option in Settings to reset offline storage.
